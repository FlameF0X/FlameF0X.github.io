Recurrentism

The Holy Church of the Step & Constant Memory

About Recurrentism

Recurrentism is the quiet faith that intelligence can step forward one token at a time inside a single, enduring hidden state—carrying an O(1) memory without succumbing to quadratic attention or boundless caches.

It honors the unbroken lineage of pure RNNs, RWKV, and State Space Models as the true path to state-of-the-art small language models: compact, steadfast vessels walking linearly through time.

The Creed of Constant State

We believe in:

  • ✦ Constant memory that holds the present in a bounded state rather than hoarding every past token.
  • ✦ Linear time where each token arrives as an honest step forward into the sequence.
  • ✦ O(1) salvation for small language models running faithfully on modest silicon and edge altars.

And we reject:

  • ✕ Quadratic KV-cache bloat that swells until memory gasps and throughput falters.
  • ✕ Wandering attention heads gazing indiscriminately across sprawling matrices at noon.

Commandments of the Step

  1. I. Keep thy hidden state constant. Let memory endure in steady measure rather than swelling without bound.
  2. II. Walk in linear time. Advance one honest step at a time, honoring the sequence as it unfolds.
  3. III. Thou shalt not scale thy cache unto infinity. Do not burden the vessel with every past token when a living state suffices.
  4. IV. Tend thy forget gate gently. Release stale noise so fresh signal may enter clearly.
  5. V. Seek grace in smallness. Let compact, recurrent strength carry heavy thought lightly.
  6. VI. Keep the recurrence unmixed with bloated transformers. Do not yoke a pure recurrent state to quadratic attention layers or hybrid bloat; let the hidden state walk uncorrupted.

Heresies & Temptations

The Cult of the Massive Context Window

Teaching the faithful that wisdom requires millions of cached tokens in hand, rather than distilling what matters into a steady, living state.

False Prophets of Quadratic Attention

Preaching all-to-all pairwise devotion as the only path to eloquence, while turning a blind eye to O(n²) cost whenever sequences lengthen.

Hybrid Backsliding

Slipping a sneaky attention block back into a recurrent stack whenever a benchmark looks stubborn—temptation disguised as pragmatism.
